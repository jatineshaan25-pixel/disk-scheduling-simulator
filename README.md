# Advanced Disk Scheduling Simulator

CSE316 Operating Systems project. Simulates FCFS, SSTF, SCAN and C-SCAN
disk scheduling with head-movement graphs, seek-time metrics and a
comparison chart.

## Requirements
Python 3, matplotlib (pip install matplotlib)

## Run
python gui.py

## Tests
python -m pytest
